# 仅有视频时的机器人观察

需要 Python 3 和 PATH 上的 ffmpeg。在本技能目录运行：

    python3 video_observations.py --video 视频.mp4 --out 本视频的独立目录

1. 读取 visual_evidence/manifest.json，依时间查看帧。每隔至少 0.5 秒取一个真实解码帧。短暂接触可能落在两个样本之间，必要时回放原视频。时间范围表示引用画面的跨度。
2. 在同一镜头内标出可辨认的部位、对象或身体参照和可见变化。使用画面左右、上下和二维距离。区分轮廓重叠、可见接触和物体反应。遮挡、机位变化或目标身份不清时写明不确定。没有外部目标时可以描述手相对肩、头或躯干的位置。
3. 写 visual_review.json。顶层 sha256 复制自清单，events 是事件列表。每条含 first、last（清单中的帧文件名）、part、target、relation 和 evidence（指出两帧或连续画面的具体变化）。relation 可取靠近、远离、相对位置稳定、部位运动、疑似接触、可见接触、分离、目标随动、可见形变、遮挡或无法判断。没有可复核事件时填空列表，并在顶层 reason 说明原因。
4. 重跑同一命令，查看 visual_report.md 与帧链接。描述目标随动或形变时保留观察依据。腕部力、力矩、压力和拉班 Weight 保持未知。单目观察只报告可见关系，静止也可能伴随持续用力。
