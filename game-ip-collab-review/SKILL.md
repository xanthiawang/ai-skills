# 游戏 IP 联名授权

具体合同/法律分析先读 [共同审查约束](../game-commercial-legal/references/core-review.md)。先确定用户代表游戏权利方、被许可方、品牌方、代理或其他参与方；没有材料不要默认我方一定是许可人。

## 把合作拆成可核对的矩阵

- 对象：游戏名称、角色/立绘/视频/音乐、商标、品牌素材、实物商品、联动食品饮品、数字礼包/CDK、宣传活动。
- 权利：复制/改编/生产/销售/宣传/分发、是否转许可、是否可委托工厂/运营门店；每项对照实际授权文本，不从一项许可推导全部。
- 范围：实体、地区、平台/门店、渠道、品类/SKU、期限、活动期与售罄期、排他范围。未知项标待确认，不自动选独家或非独家。
- 链路：权利人—签约方—代理—设计/工厂—门店/平台—消费者；实际合作可不同，不为凑链路虚构参与方。

## 审查问题

| 模块 | 需要核对的安排 |
|---|---|
| 授权与权属 | 授权链是否有材料支持，授权人能否覆盖全部素材/地区/用途？联名双方及供应商新作内容的权利和使用范围如何约定？ |
| 监修与变更 | 哪些设计、样品、宣传和上架需批准，提交材料和反馈机制是什么？不把沉默一律视为批准或一律禁止，按交易决定。 |
| 产品分类 | 正常零售、景品、赠品、特典、套餐、数字权益分别是什么？是否涉及当地消费者、安全、食品、抽奖或进口问题，需按触发事实核验。 |
| 分成与保底 | 计算对象是产量、出货、销量、零售额、实收或其他基数？赠品、捆绑、折扣、渠道留存、税费、退货、损耗如何处理？最低保证/预付是否可冲抵、范围和顺序如何？ |
| 防止漏报/重复计收 | 同一件商品是否可能同时按出货和销售重复计费？什么记录支持数量和金额，补报/差额规则是否与正文一致？ |
| 履约与质量 | 谁选工厂、生产、进口、销售、召回和处理投诉？商品或食品安全责任、保险的被保险人/产品/地区/期间是否有真实文件覆盖？保险证明不当然证明承保全部风险。 |
| 报表与付款 | 生产/出货/销售/库存记录是否能衔接？周报、月报、对账、发票和付款期限分别服务什么目的？权利方如何核查异常？ |
| 期限与退出 | 授权结束后库存、退货、销毁、线上宣传、原材料、模具、存量用户权益与应付分成如何处理？售罄不等于继续生产。 |
| 附件与一致性 | 素材包、门店、工厂、SKU、价格/费率表与监修规程是否冲突？删除附件前确认保护机制去向，不能只以页数减少作为改进。 |

如果只问“景品为什么也可能有分成”，先解释合同可能采用的计价逻辑，再指出本次需看定义和条款；不能把某合同的商业安排说成法律必然要求。

计算只使用真实数量与价格。无数据时以符号逐层写清分成口径，不自填最低数量、税率或许可费。法域、税收协定、签章和产品监管另查当时有效官方来源。

需要 Word 时复用现有合同编辑引擎，检查权限、定义、引用、附件与分成口径的一致性。内部底线、审批问题与对方可见文本分开；汇报材料可交给 `game-legal-briefing`，不循环调用路由器。
