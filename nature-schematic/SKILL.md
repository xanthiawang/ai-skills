# Nature Schematic

## Overview

Create the lab's schematic-figure house style (inherited from albert-ying's pipeline, now Zixin's default): delicate watercolor and pencil biological elements on a clean white canvas, grounded in real scientific figure references. For comparison, generate both an editable-label version and a direct imagegen-text version.

Use `imagegen` for concept art. Use `nature-figure` for real data panels. If a figure mixes both, make the schematic base here and composite real data panels from `nature-figure`; never let ImageGen invent numeric results. For ML/AI model or method architecture diagrams that must stay editable as vector (ICLR/NeurIPS/CHI-style framework and module figures), use `academic-figures-drawer` with the lab palette override described in `nature-figure`.

## Default Workflow

1. Identify the schematic units and exact labels. Keep labels short.
2. Do a scientific reference check before prompting.
   - Find 2-5 real paper/review figures for the nontrivial visual components.
   - Use the references for shape vocabulary: cells, proteins, antibodies, tubes, assays, organs, tissue architecture, pathways, and intervention icons.
   - For named proteins or placeholder proteins such as "ProteinX", do not invent an exact fold. Use a generic globular/ribbon mark unless a paper figure, review figure, PDB structure, or AlphaFold model has been checked and recorded.
   - If a component shape is not verified, simplify it to an abstract mark or omit it.
   - Record reference DOIs/URLs/figure numbers in the project metadata or final note.
3. Generate two imagegen versions:
   - **Editable-label version**: text-free base plus deterministic SVG/slide labels.
   - **Direct-text version**: labels generated by imagegen for side-by-side comparison.
4. For the editable-label base:
   - Include biological objects and generated arrows/connectors.
   - Ask for no generated text, labels, letters, numbers, units, logos, or watermark.
   - Leave a clear lower margin for labels.
5. Inspect all imagegen outputs before accepting.
   - Reject pseudo text, fake axes, fake p-values, fake sample sizes, crowded margins, or glossy 3D rendering.
   - For schematic quantification panels, use abstract marks only. No axes or numbers unless they come from real data.
   - For direct-text versions, reject misspellings, wrong counts, extra claims, and AI-slop phrasing such as "X is not Y, it is Z" unless Zixin explicitly asks for that contrast.
6. Add labels deterministically to the editable-label version.
   - Prefer editable SVG text or slide-native text boxes.
   - For exact claims, sample sizes, panel letters, and annotations, the editable-label version is the authoritative copy.
7. Save both versions.
   - SVG or slide master for editing.
   - PNG preview for quick review.
   - Direct-text PNG for comparison.
   - Metadata listing references, prompt, data sources, and which version is recommended.
   - If the artifact is project-bound, place it in the project folder instead of leaving it only under generated images.

## House Style

Use this as the default image prompt core:

```text
Wide horizontal scientific workflow illustration on a clean white background, in a delicate hand-drawn watercolor and pencil-sketch style. Muted pastel colors, translucent washes, thin gray outlines, subtle paper texture, generous whitespace, elegant biomedical research notebook aesthetic. Soft dotted gray arrows with subtle arrowheads between groups are part of the illustration. Leave clear lower margin for labels to be added later. No generated text, labels, letters, numbers, units, title, legend, logos, or watermark.
```

Preferred visual vocabulary:

- Human or tissue source: pale gray silhouette or light tissue wash, minimal detail.
- Sample: semi-transparent tube, droplet, plate, vial, or tissue section.
- Molecular layer: small protein ribbon doodles, metabolites, cells, or pathways as sparse hand-drawn marks.
- Computation or quantification: lightly ruled schematic grid, abstract dots/bars, no data-bearing axes unless real data is overlaid separately.
- Organs or outcomes: softly painted simplified icons, not detailed anatomy plates.

Avoid:

- Glossy 3D rendering.
- Saturated color.
- Heavy shadows.
- Dense text.
- BioRender-like flat vector icons.
- Generated exact labels or claims.
- Fake statistical plots or pseudo data.

## Prompt Template

```text
Use case: scientific-educational
Asset type: Nature-style biomedical schematic base
Primary request: <one-sentence schematic goal>
Reference figures: <paper/review figure URLs, DOIs, and component mapping>
Composition/framing: <wide horizontal / vertical mechanism / panel grid>. Keep objects airy and balanced. Leave clear margin for labels.
Visual groups: <ordered list of groups>. Draw generated dotted arrows/connectors between groups when useful.
Style/medium: delicate hand-drawn watercolor and pencil sketch, muted pastels, translucent washes, thin gray outlines, clean white background.
Constraints: no generated text, labels, letters, numbers, units, title, legend, logos, watermark. Quantification marks must be schematic unless real data will be overlaid separately.
Avoid: glossy 3D, heavy shadows, saturated colors, dense annotations, flat vector-icon look, fake statistical results, precise plotted data.
```

For the companion direct-text version, use the same component prompt but include the exact short labels. Keep labels concise and methods-style. Avoid explanatory filler, especially "not X, but Y" phrasing.

## Label Overlay Helper

Use `scripts/add_schematic_labels.py` when the output should be a reusable SVG master plus PNG preview:

```bash
python3 ~/programs/ai-skills/nature-schematic/scripts/add_schematic_labels.py \
  --base /path/to/generated_base.png \
  --out-svg /path/to/figure.svg \
  --out-png /path/to/figure.png \
  --label Human:0.11 \
  --label Blood:0.28 \
  --label Proteins:0.44 \
  --label Quantification:0.66 \
  --label Organs:0.87 \
  --label-y 0.87
```

Label positions are fractions of image width. `--label-y` is a fraction of image height.
PNG rendering uses `cairosvg` when it is installed in the active Python. If it is missing, the script still writes the SVG master; use `/opt/homebrew/bin/python3` on Zixin's Mac when a PNG preview is needed.

## Quality Gate

Before calling the schematic done:

- Objects, arrows, and labels align as a readable workflow.
- Nontrivial scientific component shapes were checked against real paper/review figures.
- Named proteins are either drawn from checked structure references or intentionally shown as generic abstract molecules.
- Labels are exact and editable.
- A direct-text imagegen version exists for comparison, or the metadata explains why it was rejected.
- No generated text artifacts remain in the image base.
- Generated direct-text labels, if used, were visually checked for spelling, counts, and extra claims.
- Any numeric or statistical panel either comes from real data or is clearly schematic.
- The figure still reads at the intended print width, usually 183 mm for a double-column Nature figure.
