# File Finder

Zixin's filesystem has four zones (layout surveyed and verified 2026-07-09). Understand these before searching.

## Four Zones

1. **Downloads** (`~/Downloads`) — The **intake tray**. Browser/email/app exports land here. As of the last survey it holds a backlog (~100 items); treat anything found here as "not yet routed". Broad cleanup is approval-first (see `file-organizer` and global preferences).
2. **Desktop** (`~/Desktop`) — **Project workspaces, directly at top level.** Each research project is its own folder on the Desktop; there is no `Projects/` parent. This is the organized zone, despite being the Desktop.
3. **Documents** (`~/Documents`) — **Notes and agent workspaces.** `sci-ideas/notes/` holds Dendron-style research idea notes; `Cline/`, `Codex/`, `superwhisper/` are tool workspaces.
4. **Programs** (`~/programs`) — **Skills and libraries.** `ai-skills/` (Zixin's own repo, xanthiawang/ai-skills) and `academic-forge/` (installed skill libraries).

For routing, naming, or cleanup decisions, use the `file-organizer` skill. This skill answers "where is it?"; `file-organizer` answers "where should it go?".

## Decision Tree — "Where Is That File?"

1. **Recently downloaded?** → `~/Downloads` (sort by time); if it belongs to a task, route it out before finishing.
2. **Recently staged for reading?** → `~/Desktop/Recents/`
3. **A paper draft or submission?** → `~/Desktop/StudyChat_Project/paper/{venue}/`; filenames carry dates and versions (`draft_v2_chi2027_2026-07-07.md`)
4. **Analysis data or results?** → `~/Desktop/StudyChat_Project/data/snapshots/{latest}/` for canonical; `reports/` for older auto-reports
5. **A figure?** → `paper/{venue}/figures/` next to its draft, generated by a dated script in the same folder
6. **Live study data (StudyAI)?** → GitHub `data` branch of studyai-allef, not the local deploy/ copy
7. **A research idea note?** → `~/Documents/sci-ideas/notes/`
8. **Another project's file?** → its Desktop folder (see Key Paths)
9. **A skill or agent config?** → `~/programs/ai-skills/`
10. **Can't find it?** → Glob `**/{keyword}*` across `~/Desktop` and `~/Downloads`; check `~/Desktop/Others/` last

## Authoring Pipeline (Zixin's conventions, observed in practice)

- **Quarto single source** (full adoption 2026-07-09): drafts are `.qmd`; `quarto render` regenerates review PDF + ACM PDF + coauthor docx in one command; pre-conversion `.md`/render/acm intermediates remain as archive. Quarto at `~/.local/bin/quarto`.
- **Word deliverables for coauthors/revisions** (adopted from Albert's pipeline 2026-07-09): the GLOBAL master template is `~/programs/ai-skills/manuscript-revision/assets/template.docx` (Times 11pt, Songti SC for CJK, black headings, 2.5cm margins); render with `pandoc <render>.md --citeproc --reference-doc=<template> -o <draft>.docx`; copy into a paper folder only for venue-specific styling. Revision rounds use the `manuscript-revision` skill (point-by-point response, `[..]{.mark}` highlights, CLEAN + tracked-changes dual deliverables).
- **Bilingual**: major drafts have `_CN.md` twins; technical terms stay English in Chinese text; numbers must match across versions.
- **Dated, versioned filenames**: `{name}_{YYYY-MM-DD}` everywhere; drafts as `draft_v{N}`; superseded files stay in place (or `archive/`) rather than being deleted.
- **References**: per-paper `references.bib`, every entry CrossRef/OpenAlex-verified before use.
- **Figures**: generated by scripts committed next to them (`figures/regen_*_{date}.py`); pdf+png dual format.
- **Verification scripts**: papers ship with `verify_paper_numbers_*.py` in the data snapshot; numbers in prose must trace to it.

## Delivering a File to Zixin

- **Open it directly** (`open <file>`) — she reviews PDFs in Preview; this is the default handoff for documents just built.
- **Drop it on the Yoink shelf** (`open -a /Applications/Yoink.app "<file>"`) when she will drag it elsewhere (attach to email, upload to a portal, move between apps). Multiple files: pass them all in one call. Installed 2026-07-09 via `brew install --cask yoink` (developer trial build; App Store license ~US$9 if she keeps it past the trial).
- **Reveal in Finder** (`open -R <file>`) when she needs to locate it on disk.
- **Send it inline** (harness file-send) when she wants the file in chat.
