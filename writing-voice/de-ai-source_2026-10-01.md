Specific Revision Requirements
1. Remove formulaic “not X but Y” constructions

Please identify and revise repeated or overly formulaic contrastive expressions such as:

“not because ..., but because ...”
“not merely ..., but ...”
“not only ..., but also ...”
“not a ..., but a ...”
“rather than ..., ...”
“instead of ..., ...”
“the question is not ..., but ...”

These constructions can be used sparingly when analytically necessary, but they should not appear repeatedly as a dominant rhetorical pattern.

Prefer smoother alternatives, for example:

Original:
“Multi-agent systems are not merely a scaling strategy, but organizational structures designed to compensate for bounded agent capacity.”

Possible revision:
“We treat multi-agent systems as organizational structures that may compensate for bounded agent capacity while also introducing coordination costs.”

Original:
“The question is not whether more agents are better, but under what conditions additional agents improve collective performance.”

Possible revision:
“We therefore examine the conditions under which additional agents improve collective performance.”

Please vary the revisions depending on context.

2. Reduce negative framing of prior literature

Please avoid phrasing that sounds dismissive of existing studies.

Revise harsh or overly negative formulations such as:

“existing studies fail to...”
“the literature lacks...”
“current work does not...”
“these studies ignore...”
“prior research has not theorized...”
“this is inadequate...”

Use limitation-oriented and contribution-oriented language instead:

“existing studies have made important progress, while leaving open...”
“this literature creates an opportunity to...”
“a remaining limitation is...”
“less attention has been paid to...”
“the organizational implications remain underdeveloped...”
“our framework complements this work by...”
“we build on this literature by...”

The section “Limitations of Current Multi-Agent AI Studies” should still identify limitations clearly, but it should do so in a balanced, respectful, and academically constructive tone.

3. Use subject-position expressions to reduce over-assertiveness

Please revise the manuscript so that the authors’ perspective is clearly signaled. Use phrases such as:

“we propose”
“we examine”
“we conceptualize”
“we treat”
“we suggest”
“we expect”
“we argue”
“we draw on”
“we use this metaphor to”
“we develop this framework to”
“our approach emphasizes”
“our proposal is to”

This does not mean every paragraph must begin with “we.” Use these expressions naturally to clarify that the paper is advancing an analytical framework rather than making absolute claims.

For uncertain or context-dependent claims, use moderated language:

“may”
“can”
“could”
“is likely to”
“under some conditions”
“in this setting”
“we expect”
“we suggest”
“a plausible implication is”
“this creates the possibility that”

Avoid overly assertive universal claims such as:

“X always...”
“Y necessarily...”
“Z proves...”
“the best structure is...”
“this shows that...”

Prefer:

“X may...”
“Y is likely to...”
“Z suggests...”
“one expected pattern is...”
“this framework implies...”
4. Preserve theoretical clarity

Do not make the prose vague. The revision should remain theoretically sharp.

Keep the core distinctions clear:

bounded rationality vs. context-window limitation;
span of control vs. number of agents;
search diversity vs. coordination cost;
consensus-based deliberation vs. voting-based aggregation vs. orchestrator-centered authority;
high-verifiability tasks vs. low-verifiability tasks;
pooled, sequential, and reciprocal interdependence;
mechanistic vs. organic organization;
coding tasks vs. GAIA-style knowledge/tool-use tasks vs. open-ended writing tasks.
5. Improve paragraph flow

Please revise paragraphs so that each paragraph has:

a clear topic sentence;
a coherent conceptual progression;
no excessive repetition;
smooth transitions between organization theory and AI systems.

If a paragraph feels like a list of claims, rewrite it into a more connected argument.

If two paragraphs repeat the same point, consolidate them.

If a paragraph is too long, split it.

6. Reduce AI-like repetition

Please remove or reduce repeated phrases such as:

“This study...”
“This framework...”
“The core claim...”
“In this sense...”
“This suggests that...”
“The key point is...”
“The central expectation is...”
“Taken together...”
“In other words...”

Use them only when they improve clarity. Vary sentence structures and transitions.

7. Keep citations intact

Preserve all author-year citations and reference-list entries.

Do not delete citations unless the cited claim has been removed.

If a citation seems misplaced, move it to the sentence where it best supports the claim.

If a reference appears in the bibliography but no longer appears in the text, mark it with [CHECK: cited?].

If a claim needs a citation but does not have one, add [CITATION NEEDED] rather than inventing a source.
