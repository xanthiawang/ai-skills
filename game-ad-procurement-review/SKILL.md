# 游戏广告与营销采购

仅做概念解释时先给直接中文答案。审具体合同或给法律结论前读 [共同审查约束](../game-commercial-legal/references/core-review.md)；涉及平台机制再查 [资料入口](../game-commercial-legal/references/source-entrypoints.md) 及真实供应商资料。引用不可用时保留待核实，不宣称已完成审查。

## 先识别实际合作，不靠公司标签推定

区分创意制作、KOL/公关、媒体代理、媒介转售、自助平台、DSP优化技术、SSP/媒体供给、广告交易、MMP/归因与数据服务。一个合作可组合多个功能。

解释术语时写出必要全称、站在哪一侧、为谁提供什么、谁付什么钱、报告什么结果。MMP 的测量角色不当然让它承担媒体购买或交付义务；对方用了第三方系统也不当然免除自己的合同义务。

## 对照真实协议检查

| 模块 | 应确认的问题 |
|---|---|
| 合同链与权限 | 主协议、IO/SOW、平台条款、第三方规则、费率和数据附件如何衔接？谁能下单、增加预算、批准超支和改动范围？ |
| 钱与费用 | 广告预算、代理费、平台/技术费、制作费、差旅等开支、返点/credit分别是什么？原价、净价、成本加成或包干口径是否清晰？ |
| 资金与关联方 | 谁出资、谁订约、谁收返点/开票、谁承担欠款？代付、加入合同与单独订约的效果分别核实，不能混称“关联方安排”。 |
| KPI与验收 | impressions、clicks、installs、events、ROAS等是否在本合同有定义、目标、期间、来源和责任？展示/投放承诺与不保证业绩的优化服务是否区别？ |
| 归因与争议 | 平台报告与MMP为何可能不同，归因窗口、时区、去重、数据延迟与校正如何约定？合同用哪个来源验收，差异争议如何处理？ |
| 无效流量与未达标 | 欺诈/无效流量由何种证据判定？重投、退款、credit或其他补救是什么？别默认某种补救当然适用，也不捏造欺诈率。 |
| 费用审批 | 超预算、未经批准开支、媒体/人员替换、转委托与变更是否有可操作机制？谁确认商业取舍？ |
| 素材与权利 | 素材、账号、数据、创意成品和源文件各归谁/可用到何时？是否超范围使用未公开角色、品牌资产或用户内容？ |
| 数据与隐私 | SDK/标识符/用户行为/受众名单实际由谁取得、决定用途、共享和保留？技术供应商不等于固定法律角色；DPA、分包、跨境与安全问题由实际事实触发。 |
| 退出与追踪 | 暂停投放、撤销授权、账号访问、剩余预付款、未结订单、成品交付、数据保留/删除和最终对账如何收尾？ |

## 交付

需要时输出：业务链路简图/表、术语大白话、条款位置与问题、最小修改建议、业务/财税/数据/法务确认项。保留指标、期间、币种、版本和来源；没有实际报表就不计算或估计投放效果。

对当前法律、平台政策和归因产品行为使用一手资料核验，不把技术建议写成所有地区的法律要求。复用现有合同/文档技能处理真实 DOCX；不自动接受条款、提交审批、发信或调整广告账户/预算。
